# Walkable workshop asset provenance

## Original project meshes

The 28 FBX modules in `Models/` were authored for Little Switch with Blender. Editable generation source: `Tools/build_walkable_workshop.py` at repository root. Beveled furniture, modeled drawers/hardware, timber joinery, recessed windows, pegboard, soldering equipment, multimeter, bottles, keyboard displays, cable loops, brushes, tape, paperwork, noticeboards, apron and exterior trees are original project geometry. They are not extracted from the reference image. The scene uses imported mesh assets; it does not construct furniture from Unity primitives at runtime.

The existing original RetroComputer and CompartmentTray meshes are reused. The measuring grid is an original generated texture. Displays and paper schematics contain original simple marks, with no third-party logos.
